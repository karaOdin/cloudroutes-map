- Searching now returns stops as results in their own right. It used to filter the line list, so typing a stop's name returned a set of line cards with no indication of which stop had matched or why — the answer was buried inside a collapsed card. Matching stops are now listed directly, with the matched run marked, the lines serving each one as coloured chips, and a tap that flies to the stop and calls it out. Matching lines are listed below under their own heading.
